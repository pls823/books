# AI 协作写小说工作流

## 1. 增：新增内容

适合用于扩写脑洞、补充人物、生成新章节。

示例指令：

```text
请基于 story/ideas/inbox.md 的核心设定，新增一个主角人物卡，写入 story/characters/protagonist.md。
```

## 2. 删：删除内容

适合删掉重复设定、废弃剧情线、无效章节片段。

示例指令：

```text
请检查 story/worldbuilding/timeline.md，删除明显重复或互相矛盾的事件，并说明删除原因。
```

## 3. 改：改写内容

适合调风格、改节奏、修逻辑、统一口吻。

示例指令：

```text
请改写 story/volumes/001-开篇.md，让叙事更有悬疑感，保留所有已发生的剧情事实。
```

## 4. 查：查询与审校

适合检查人物一致性、时间线矛盾、伏笔回收、设定冲突。

示例指令：

```text
请对比 story/characters/ 和 story/volumes/，列出角色动机不一致的地方。
```

## 5. 推荐文件粒度

- 每个章节一个文件。
- 每个主要角色一个文件。
- 每个大型地点、组织或能力体系一个文件。
- 灵感池可以先集中在一个文件，稳定后再拆分。

## 6. 与 AI 协作时的注意事项

- 明确指定要改哪个文件。
- 说明是否允许改剧情事实。
- 说明目标风格，例如“更冷峻”“更口语”“更古典”“更网文节奏”。
- 大改前先要求 AI 给出修改计划。
- 重要设定改动后同步更新人物卡、时间线和世界观文件。
