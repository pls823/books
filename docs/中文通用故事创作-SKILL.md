# 中文通用故事创作 Skill

## 适用范围

用于中文小说、短篇故事、系列故事、世界观设定和章节草稿的生成、改写、续写与审校。

## 创作原则

1. **先定核心冲突**：明确主角想要什么、阻碍是什么、代价是什么。
2. **先搭骨架再写正文**：先产出题材、卖点、人物、世界观、小纲，再进入章节写作。
3. **保持人物一致性**：角色的欲望、恐惧、口吻和行动方式要前后一致。
4. **每章有推进**：每一章至少推动剧情、人物关系、世界观认知或悬念之一。
5. **保留可追踪设定**：重要设定、伏笔、时间线变化要同步记录，避免后续矛盾。

## 标准流程

### 1. 项目初始化

- 确定故事名称、类型、基调和目标读者。
- 写一句话故事梗概。
- 列出 3 到 5 个核心看点。

### 2. 设定阶段

- 创建主角、反派、关键配角的人物卡。
- 创建世界观、组织、能力体系、地点和时间线。
- 明确故事规则与限制，尤其是能力、金钱、权力或命运相关设定。

### 3. 大纲阶段

- 先写三幕式或卷纲。
- 再拆成章节小纲。
- 每章记录：目标、冲突、反转、结尾钩子。

### 4. 正文阶段

- 按章节生成正文。
- 生成后检查：节奏、人物动机、信息密度、悬念、语言风格。
- 需要时进行多轮改写，但不要随意改动已确认的剧情事实。

### 5. 审校阶段

- 检查时间线矛盾。
- 检查人物口吻和行为是否一致。
- 检查伏笔是否有记录、是否需要回收。
- 检查章节之间是否有重复信息或断裂。

## 常用指令模板

```text
请根据当前故事设定，生成一个主角人物卡，包含欲望、恐惧、弱点、人物弧光和口吻特征。
```

```text
请把这一章改写得更有悬疑感，但保留所有剧情事实，不新增关键设定。
```

```text
请检查当前故事集中的人物、时间线和世界观文件，列出可能矛盾的地方。
```

```text
请基于章节小纲生成正文，风格要求：中文网文节奏、强钩子、段落短、结尾留悬念。
```

## 输出格式建议

- 设定与模板优先使用 Markdown。
- 每个故事单独一个文件夹。
- 每章单独一个 Markdown 文件。
- 人物、世界观、时间线、伏笔清单分文件维护。
